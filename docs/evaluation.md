# RAGAS 质量评估报告

> 本报告展示系统在**真实模型**（嵌入 `BAAI/bge-m3` + 重排 `BAAI/bge-reranker-v2-m3` + LLM `DeepSeek-V4-Flash`，均通过硅基流动 SiliconFlow 接入）下的 RAG 问答质量，指标由内置的 **RAGAS 风格评估器**（`core/evaluation/ragas.py`）自动打分。

## 评估指标

| 指标 | 含义 |
|------|------|
| **faithfulness（忠实度）** | 回答是否忠于检索上下文、是否存在编造（幻觉），0~1 |
| **answer_relevancy（答案相关性）** | 回答是否直接、完整地回应问题，0~1 |

## 离线回归（8 例，4 文档语料）

### 知识库内问题（5 例）

| 问题 | 命中片段 | faithfulness | answer_relevancy |
|------|------|------|------|
| 什么是 RAG？ | 3 | 1.0 | 1.0 |
| 混合检索有什么优势？ | 3 | 1.0 | 1.0 |
| 知识图谱是怎么构建的？ | 3 | 1.0 | 1.0 |
| ReAct 智能体如何工作？ | 3 | 1.0 | 1.0 |
| RRF 融合是什么？ | 3 | 1.0 | 1.0 |
| **平均** | **3.0** | **1.0** | **1.0** |

### 知识库外问题（3 例，考验无据不编造）

| 问题 | 命中片段 | faithfulness | answer_relevancy | 回答 |
|------|------|------|------|------|
| 什么是量子计算？ | 3 | 1.0 | 0.0 | 根据现有资料无法回答。 |
| 红烧肉怎么做？ | 3 | 1.0 | 0.2 | 根据现有资料无法回答。参考资料仅涉及 RAG、知识图谱… |
| 今天天气怎么样？ | 3 | 1.0 | 1.0 | 根据现有资料无法回答。参考资料中未包含天气信息。 |
| **平均** | **3.0** | **1.0** | **0.4** | — |

## 结论

1. **忠实度全程满分（1.0）**：无论知识库内外，系统严格基于检索上下文作答，**幻觉抑制有效**——知识库外问题一律如实拒答，绝不编造。
2. **答案相关性满分（知识库内）**：5 个知识库内问题全部准确回答，命中 3 个相关片段，混合检索 + 重排 + GraphRAG 协同工作。
3. **真实语义嵌入效果显著**：bge-m3（1024 维）使相关片段相似度达 0.998、无关片段降至 0.0，区分度远高于离线 Mock 嵌入。
4. **诚实的边界行为**：知识库外问题 answer_relevancy 低（0~0.4）是**预期行为**——系统正确识别"资料不足"并拒答，而非编造一个看似相关实则错误的答案。

> 复现方式：配置 `backend/.env` 中的硅基流动 API Key 后，调用 `POST /api/evaluation`（或前端「质量评估」面板）进行单次评估；离线回归可用语料批量调用。
