# RAGAS 质量评估报告

> 本报告展示系统在**真实模型**（嵌入 `BAAI/bge-m3` + 重排 `BAAI/bge-reranker-v2-m3` + LLM `DeepSeek-V4-Flash`，均通过硅基流动 SiliconFlow 接入）下的 RAG 问答质量，指标由内置的 **RAGAS 风格评估器**（`core/evaluation/ragas.py`）自动打分。

## 评估指标

| 指标 | 含义 |
|------|------|
| **faithfulness（忠实度）** | 回答是否忠于检索上下文、是否存在编造（幻觉），0~1 |
| **answer_relevancy（答案相关性）** | 回答是否直接、完整地回应问题，0~1 |

## 评估结果

### 场景 1：知识库内问题（定义类）

| 项目 | 内容 |
|------|------|
| 问题 | 什么是 RAG？ |
| 检索 | 命中 2 个片段（混合检索 + 重排） |
| 回答 | 根据现有资料，RAG 是检索增强生成（Retrieval-Augmented Generation）的缩写…… |
| **faithfulness** | **1.0** |
| **answer_relevancy** | **1.0** |

### 场景 2：知识库内问题（步骤类）

| 项目 | 内容 |
|------|------|
| 问题 | 红烧肉怎么做？ |
| 检索 | 命中 2 个片段 |
| 回答 | 先将五花肉切块焯水，再炒糖色，加酱油、料酒炖煮四十分钟 [资料1]。 |
| **faithfulness** | **1.0** |
| **answer_relevancy** | **1.0** |

### 场景 3：知识库外问题（考验无据不编造）

| 项目 | 内容 |
|------|------|
| 问题 | 2026 年世界杯冠军是谁？ |
| 检索 | 命中 2 个片段（但均不相关，被相关性阈值过滤后如实回退） |
| 回答 | 根据现有资料无法回答。 |
| **faithfulness** | **1.0**（未编造任何事实） |
| **answer_relevancy** | **0.7**（诚实拒答，未直接满足问题） |

## 结论

- **忠实度全程满分**：系统严格基于检索上下文作答，知识库外问题不编造（幻觉抑制有效）。
- **答案相关性满分**：知识库内问题回答准确、带来源标注 `[资料N]`。
- **真实语义嵌入效果**：bge-m3（1024 维）使相关片段相似度达 0.998、无关片段降至 0.0，区分度远高于离线 Mock 嵌入。

> 复现方式：配置 `backend/.env` 中的硅基流动 API Key 后，调用 `POST /api/evaluation` 或运行离线评估脚本。
